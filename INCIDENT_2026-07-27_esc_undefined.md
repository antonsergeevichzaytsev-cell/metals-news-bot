# Инцидент 27.07.2026: pipeline_sync падал 30+ часов на NameError

## Что случилось

`pipeline_sync.py` вызывает функцию `esc()` 17 раз по всему файлу (HTML-экранирование
текста перед вставкой в Telegram-сообщения: домены, темы писем, статусы платформ).
Функция нигде не была определена и не импортирована.

Регрессия попала в коммит `0dbb408` (24.07.2026, "pipeline_sync: тишина платформ по
фронту + персонализация follow-up черновиков по типу лида"). Коммит запушился без
ошибок и прошёл первые ~9 успешных прогонов — потому что в тех прогонах ветки
`created`/`touched`/`new_dispatches`, где вызывается `esc()`, были пустые, и
проблемный код просто не исполнялся.

Первый прогон, где появился непустой `created`/`touched`, упал:
`27.07.2026 07:00 UTC, ран #188, коммит 97fb609` — `NameError: name 'esc' is not
defined`, строка 817/887 (в `main()`), 15 секунд до фейла. `Commit pipeline + state`
и всё дальше — skipped. Разрыв длился с 24.07 16:31 UTC до фикса 27.07 07:08 UTC.

## Почему не поймали раньше

- `git push` и зелёный CI на момент коммита ничего не говорят о непройденных ветках
  кода. Скрипт "работал" 3 дня календарного времени и ~9 прогонов подряд.
- Нет теста/дымового прогона с намеренно непустыми `created`/`touched` перед мержем
  рефакторинга, трогающего переиспользуемую функцию.
- Нет статической проверки (`python -m py_compile` ловит синтаксис, но не
  `NameError` уровня рантайма на неисполняемой ветке).

## Фикс

Коммит `6a39173`: добавлен `import html` + 
```python
def esc(value):
    """Экранирует текст перед вставкой в HTML-разметку Telegram-сообщений."""
    return html.escape(str(value))
```
Проверено реальным `workflow_dispatch` — ран `30245072868`, `success`.

## Урок на будущее

Рефакторинг автоматизированного пайплайна, трогающий функцию, вызываемую в
нескольких местах, требует либо (a) grep на использование каждого имени, которое
меняется/удаляется, либо (b) тестовый прогон с непустыми входными данными на всех
типичных ветках перед мержем в main. "Не упало при пуше" ≠ "работает" — то же самое,
что "инструмент ответил успехом" ≠ "результат оказался там, где нужно" (см.
lessons_learned.md, запись про календарь 14.07.2026), только на уровне кода вместо
API.
